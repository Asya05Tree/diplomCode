# Adversarial findings — TAB 09 Навчання (Study)

Live reproduction against `http://localhost:5080` (backend running) + MySQL `planner-mysql`.
PoCs: `adversarial-review/poc/09-study/*.mjs` (each prints `CONFIRMED`/`REFUTED`, observed vs expected).
Source read-only; nothing fixed.

Verdict legend: 🔴 critical · 🟠 significant · 🟡 moderate · ⚪ minor · ⚪ **REFUTED** (claim does not hold).

> TOP RESULT: The module is **not gated server-side at all**. A `studentType:'none'` account drives the whole Study API and persists data (PoC 01). Plus a real cross-user data leak (IDOR, PoC 03) and a persisted payload that 500s the shared planner (PoC 07).
