## 1. Фронтенд — сторінка, картки, фільтр розділів, логіка

- **1.1 🟠 Немає обробки помилок у хендлерах.** CONFIRMED (static). `handleAdd/handleDelete/handleCategoryChange/confirmCheck/handleSuggestion/handleReceipt/handlePlanTrip` call `apiSend`, which throws on non-2xx (`api/http.js:27`), with no `try/catch`. Evidence: `ShoppingList.jsx:88-138`. `error` state is set only in the initial `useEffect` (`:75`). Impact: silent failures, unhandled promise rejections — e.g. the 404/500 responses produced by PoCs `price-validation.mjs`/`data-limits.mjs` would surface to the user as a frozen UI.
- **1.2 🟠 `reload()` без catch.** CONFIRMED (static). `reload` (`:58-63`) awaited after every action; a failed re-GET leaves stale UI and no error. Same root as 1.1.
- **1.3 🟠 Немає блокування повторних кліків.** CONFIRMED. No button is disabled during the request (`:182-391`). Server-side consequence proven: `plan-trip-spam.mjs` → 5 rapid calls create 5 tasks (DB holds 15 cumulative). See 9.x / 11.3.
- **1.4 🟡 Форма лише назва; немає повернення фокусу.** CONFIRMED (static). `handleAdd` clears `name` (`:95`) but does not refocus the input — UX friction for bulk entry.
- **1.5 🟡 Фільтр розділу «залипає».** CONFIRMED (static). `presentSections` (`:177`) drops a section once its last item is removed, but `sectionFilter` (`:43`) is never reset → `visibleItems` (`:178`) becomes empty and shows "empty list" while other sections have items.
- **1.6 🟡 `guessShoppingCategory` на клієнті.** CONFIRMED (static). Categorization runs in `handleAdd` (`:93`); server `AddItemAsync` takes `category` as-is (`ShoppingService.cs:122-139`). Cross-module additions would diverge.
- **1.7 🔵 Картка показує `displayName` (CustomText = Uk=En).** CONFIRMED (static). `DisplayName` returns `(text,text)` for CustomText (`ShoppingService.cs:87-88`); mixed-language list is inconsistent. By-design note.
- **1.8 🟡 Чекбокс «куплено» незворотний.** CONFIRMED (static). `disabled={item.isChecked}` (`:213`); no un-check endpoint exists in controller. Accidental check is irreversible except by delete — and stock/price/expense already written (see §9).

## 3. Валідація вводу, стани (loading/error/empty)

- **3.1 🟡 loading/error лише для первинного завантаження.** CONFIRMED (static). `:160-173` cover init only; actions have no states (see 1.1).
- **3.2 🟡 Порожній стан залежить від фільтра.** CONFIRMED (static). `visibleItems.length===0` → "empty" (`:203-204`) even when the list is non-empty but a section filter is active. Tied to 1.5.
- **3.3 🟠 Ціна при відмітці без верхньої валідації перед відправкою.** CONFIRMED (live). `confirmCheck` uses `Number(checkPrice)` (`:116`); `NumberStepper` clamps to `[0, money.max]` only on blur/buttons (`NumberStepper.jsx:40-46`). Server has no bound at all — proven by `price-validation.mjs`: `1e15` accepted (HTTP 200), `1e16` → HTTP 500.
- **3.4 🟡 Нуль при відмітці записує ціну 0.** CONFIRMED (static). `confirmCheck`: `checkPrice !== ''` → `price=0` passed (`:116`); server writes `EstimatedPrice=0`, Expense 0, overwrites product price with 0 (`ShoppingService.cs:175,180,194-205`).
- **3.5 🟡 Проміжний стан `'.'` у NumberStepper.** CONFIRMED (static). `sanitize` can yield `'.'` (`NumberStepper.jsx:26-34`); `Number('.')=NaN`. Guards rely on `=== ''` only (`:116,129`), so `'.'` could pass `NaN` to the server. Low likelihood (blur clamps), noted.
- **3.6 🟡 Назва не обмежена за довжиною на клієнті.** CONFIRMED (live). Only `trim()` (`:90`); no `maxLength`. See 10.5 — `data-limits.mjs` stored a 5000-char name.

## 8. Безпека (XSS, mass assignment)

Pollutes finance categories with arbitrary/huge values.
- **8.3 🟡 Невідомий ключ категорії показується сирим.** CONFIRMED (static). `shoppingCategoryName` returns the key as-is for unknown keys (`shoppingCategories.js:48-52`) → junk visible in select `title` (`:230`). React escapes → no XSS, just garbage.
- **8.4 🟢/🟠 Section whitelist OK, але category↔section розсинхрон.** CONFIRMED (live). Section whitelist works (`ShoppingService.cs:125`; bad section → 400). But `SetCategory` never updates Section. - **8.5 🟡 `FinanceTransaction.Description = nameUk` (raw).** CONFIRMED (static). `ShoppingService.cs:196,204`. Same escape-dependence as 8.1.

## 9. Бізнес-логіка та інваріанти

### Автокатегоризація
- **9.1 🔴 «паста» → Гігієна, не Бакалія.** CONFIRMED (live, unit). PoC `autocategorization.mjs`: `паста → hygiene (Cosmetics)`. `'паст'` in the `hygiene` rule (`shoppingCategories.js:63`) ranks above `'макарон'` in `grocery` (`:74`); substring + first-match-wins. Spec demo item "паста 110 грн" miscategorized.
- **9.2 🟡 Інші підрядкові конфлікти.** CONFIRMED (live, unit). `чайник → grocery` (via `'чай'`, should be home). `олівець → stationery` correct only because `'олівец'` ranks above `'олі'`. Order is load-bearing and brittle.
- **9.3 🟡 Порядок правил = недокументований контракт.** CONFIRMED (static). `KEYWORDS` order (`shoppingCategories.js:61-77`) is the priority; no tests, easily broken on edit.
- **9.4 ⚪ Невідома/порожня назва → 'other'.** REFUTED (verified-OK). `guessShoppingCategory` (`:80-87`) returns 'other' correctly.
- **9.5 🟡 Unicode-апостроф ламає категоризацію.** CONFIRMED (live, unit). PoC: `мясо → meat_fish`, `м'ясо (U+0027) → meat_fish`, but `мʼясо (U+02BC) → other`. The key `"м'яс"` (`:68`) uses U+0027; modifier-letter apostrophe not matched.

### Ціна/витрата/запас
- **9.6 🔴 Негативна/величезна ціна при відмітці.** CONFIRMED (live). See 6.1 — `-500` → negative Expense (income disguised); `1e16` → 500 overflow. PoC `price-validation.mjs`.

Expense (`:194-206`) is created for any source with a price (verified-OK that medicines with price do get an Expense).
- **9.8 🟡 Відмітка без ціни оновлює запас/історію, не ціну/витрату.** CONFIRMED (static). `price.HasValue` guards (`:175,180,194`). Consistent with spec.

- **9.9 🔴 Подвійний облік витрат.** CONFIRMED (live). - **9.11 🟠 Решта < 0 → обрізається до 0, але Expense = повний total.** CONFIRMED (static+live). `remainder = Math.Max(0m, total-knownSum)` (`:238`); if total < knownSum, perItem=0 but full `total` Expense still written (`:250`). Compounds 9.9.
- **9.12 🟠 Втрата залишку при округленні.** CONFIRMED (static). `perItem = Round(remainder/unknown.Count, 2)` (`:239`); last item not corrected → Σ perItem ≠ remainder (e.g. 10/3).
- **9.13 🟡 `unknown.Count==0` → Expense на total без позицій.** CONFIRMED (live). PoC `finance-double-count.mjs` (fresh user): receipt total 777 with nothing checked → split `[]` but **Expense 777 recorded** (`:239,250-258`). Arbitrary expense injection.
- **9.14 🟡 Чек перезаписує реальні особисті ціни усередненим perItem.** CONFIRMED (static). `UpsertPriceAsync(..., perItem)` (`:245`) overwrites `UserProductPrice.LastPrice` with possibly 0 — distorts price history.
