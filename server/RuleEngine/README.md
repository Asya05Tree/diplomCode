# RuleEngine

Ключовий компонент (planner-spec.md §2.2–2.3). Один рушій для всієї системи: перевірка перетину тегів об'єкта
із забороненими/бажаними тегами користувача (`UserTagPreference`, `Rule`). Використовується фільтрацією блюд,
перевіркою ліків, перевіркою задач — окремої логіки для кожного домену тут бути не повинно.

Заплановано на 3-й місяць (planner-spec.md §7): `TagMatcher`, `RuleEvaluator`.
